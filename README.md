# RALLYLED · paquetes de fábrica

Firmware y diseños del marcador RALLYLED, **firmados y cifrados**. Cada release es un paquete
completo; la marcada como *Latest* es la que usa la herramienta de fábrica.

Estos ficheros no sirven por sí solos: se instalan solo con la herramienta de fábrica de
RALLYLED y un lote autorizado.
